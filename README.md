# EROMZA IT Solutions — College Portal

## Project Overview
We are building a College Portal to manage college departments, HODs, teachers, announcements, and academic records.

## Project Goal
Create a working website with secure login, role-based dashboards, and department-level access.

## Main User Roles
1. College Administrator
2. HOD / Department Coordinator
3. Teacher
4. Office Staff and Student — optional future modules

## Project Modules
- Login and authentication
- Role-based dashboards
- Department management
- Teacher profiles
- Announcements
- Academic records and timetables
- Reports and document management

## Development Rules
- Every intern must complete their assigned task.
- Every task must have a GitHub Issue.
- Submit code through a Pull Request for review.
- Do not upload passwords, secret keys, or real college data.
- Explain and demonstrate your work during code reviews.

## First Milestone
Confirm the technology stack, set up the project structure, and develop the first login-page interface.
